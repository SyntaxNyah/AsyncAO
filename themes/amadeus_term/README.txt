Amadeus Terminal - an AsyncAO theme
Screen-glow cyan on near-black, mono everywhere, with one cold-cathode readout
in amber for a counterpoint. The chat log lives inside a handset card built to
measured phone proportions, and the chatbox is the message it just received.

INSTALL: drop this folder into your AsyncAO themes/ folder, then pick
"Amadeus Terminal" in Settings. Nothing else to do.

ALL ART IS PROCEDURAL. This theme ships zero bytes of image, font or audio:
every surface is generated at runtime from the colours, shapes and numbers in
asyncao_theme.ini, and the readout numerals are this client's own version
string. Original work, AGPLv3-compatible.

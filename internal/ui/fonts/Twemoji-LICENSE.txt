Twemoji — colour emoji artwork
==============================

Bundled file: Twemoji.ttf  (COLRv0 / CPAL colour font)

This font is an ADAPTATION of the Twemoji emoji artwork: the upstream SVG
sources were compiled into layered COLR/CPAL outlines for use as AsyncAO's
colour-emoji fallback face. The artwork designs themselves are unchanged.

Changes made by AsyncAO (CC BY 4.0 section 3(a)(1)(B)):
  - The 4009 upstream SVGs were compiled into a COLRv0/CPAL OpenType font with
    googlefonts/nanoemoji (Apache-2.0), a build-time tool that is not itself
    redistributed here. See scripts/build-emoji-font.ps1 for the exact recipe.
  - Font metrics were set to upem 512, ascender 448, descender -64, linegap 56,
    advance width 512, so the glyph box matches the font this replaced and emoji
    do not change size in existing chat logs.
  - One source file, 1f349.svg (watermelon), was re-wrapped from its upstream
    viewBox "0 0 36 25.22" into a "0 0 36 36" square with the artwork vertically
    centred, so the font builder does not stretch it. No path data was altered.
  - No previous modifications are carried over: this is a fresh build directly
    from jdecked/twemoji, not a rebuild of another party's font.
